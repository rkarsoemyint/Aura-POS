Aura POS - Modern Point of Sale System

Aura POS သည် Python (Django) နှင့် Tailwind CSS ကို အသုံးပြု၍ တည်ဆောက်ထားသော ခေတ်မီပြီး သေသပ်လှပသည့် Point of Sale (POS) System တစ်ခုဖြစ်ပါသည်။ ဤစနစ်ကို အသေးစားနှင့် အလတ်စား စီးပွားရေးလုပ်ငန်းများအတွက် အရောင်းစာရင်း၊ ပစ္စည်းစာရင်း (Inventory) နှင့် အရောင်းအစီရင်ခံစာ (Sales Reports) များကို လွယ်ကူစွာ စီမံခန့်ခွဲနိုင်ရန် ရည်ရွယ်၍ ဖန်တီးထားခြင်း ဖြစ်ပါသည်။

Key Features

Dashboard: တစ်နေ့တာ အရောင်းစာရင်း၊ အော်ဒါအရေအတွက်နှင့် ပစ္စည်းလက်ကျန် အခြေအနေများကို Chart များဖြင့် မြင်ကွင်းကျယ် ကြည့်ရှုနိုင်ခြင်း။

POS Terminal: မြန်ဆန်ချောမွေ့သော အရောင်း Process နှင့် Invoice ထုတ်ပေးနိုင်ခြင်း။

Inventory Management: ကုန်ပစ္စည်းများကို အမျိုးအစား (Category) အလိုက် စနစ်တကျ စီမံနိုင်ခြင်း။

Sales Reports: အရောင်းမှတ်တမ်းများကို အသေးစိတ်စစ်ဆေးနိုင်ပြီး Excel သို့မဟုတ် PDF ထုတ်ယူနိုင်ခြင်း။

Staff Roles: Admin နှင့် Staff (Cashier) ဟူ၍ ခွဲခြားထားပြီး Access Permission များကို စနစ်တကျ ကန့်သတ်ထားခြင်း။

Responsive UI: ဖုန်း၊ တက်ဘလက် နှင့် ကွန်ပျူတာ အားလုံးတွင် အဆင်ပြေပြေ အသုံးပြုနိုင်သည့် Modern Dark/Light Mode UI။


 Tech Stack

Backend: Python 3.x, Django Web Framework
Frontend: Tailwind CSS, DaisyUI (Components Library)
Database: SQLite (Demo အတွက် အသုံးပြုထားပါသည်)
Icons: FontAwesome 6
